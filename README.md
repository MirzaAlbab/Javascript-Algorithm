# Javascript-Algorithm

JavaScript challenge solutions and console examples for practicing algorithms and input validation.

[Repository](https://github.com/MirzaAlbab/Javascript-Algorithm)

## Features

- String and input-validation exercises
- Email and password validation examples
- Name parsing and other challenge functions
- Jest dependency and a test script

## Getting started

Install Node.js.

```bash
git clone https://github.com/MirzaAlbab/Javascript-Algorithm.git
cd Javascript-Algorithm
```

```bash
npm install
node script.js
```

Alternatively, serve `index.html` locally and inspect the browser console.
